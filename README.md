# Pantalla de agenda de las salas de juntas — paquetes (MESABI)

Este repositorio solo contiene los **paquetes publicados** de la pantalla de agenda de las salas de juntas de MESABI / LyM. Las pantallas los descargan solas cada día (06:20) y verifican su SHA-256 antes de instalarlos.

## Activar o reparar las actualizaciones en un PC de sala

1. En el PC de la sala, abre **Releases → la versión más reciente** y descarga **`ACTIVAR-ACTUALIZACIONES.cmd`**
   (enlace directo: https://github.com/SoporteMesabi/pantalla-sala-releases/releases/latest/download/ACTIVAR-ACTUALIZACIONES.cmd).
2. Doble clic. Si Windows avisa "Windows protegió su PC": **Más información → Ejecutar de todas formas**. Pide credenciales de administrador.
3. Si es la primera vez, pega la URL del webhook de Teams cuando la pida.

El código fuente y la documentación viven en el workspace interno de Sistemas (`05_HERRAMIENTAS_INTERNAS\Pantalla_Sala_Juntas`).
